# موقع DJ Rabih Jamal — دليل الرفع (GitHub + Vercel)

## ⚠️ قبل ما تنشر — مهم جداً

نموذج الحجز الكبير (7 خطوات، زر "تعبئة نموذج تفاصيل الحفل") بيحفظ الطلبات حالياً عن طريق
`window.storage` — وهاد نظام تخزين خاص ببيئة معاينة Claude بس، **مش رح يشتغل على موقع حقيقي منشور على Vercel**.
يعني لو نشرت الموقع هيك متل ما هو، الزبون رح يعبي النموذج ويضغط "إرسال" وما رح توصلك التفاصيل بأي مكان.

نموذج الحجز السريع (زر "احجزوا حفلكم الآن" بالهيرو) شغّال تمام لأنه بيرسل مباشرة عبر واتساب.

**الحل — لازم تختار وحدة من هالخيارين قبل ما تشارك الرابط مع الزبائن:**
- **أسرع حل:** خلي النموذج الكبير يرسل عبر واتساب زي النموذج السريع بالضبط (بس اطلب مني هالتعديل، بياخد دقايق)
- **حل أفضل للمدى الطويل:** نربط قاعدة بيانات حقيقية (Supabase مجاني) عشان كل الطلبات تنحفظ ولوحة تحكم توصلك فيها كل الطلبات

## الخطوة 1: رفع الملفات على GitHub

1. روح على [github.com](https://github.com) واعمل حساب (إذا ما عندك)
2. اضغط **New repository** (زر أخضر أعلى الصفحة)
3. سمّي الريبو مثلاً `jamal-production-website` واختار **Public** أو **Private**، ثم **Create repository**
4. بالصفحة يلي بتفتح، اضغط **uploading an existing file**
5. اسحب **كل محتويات هالمجلد** (بما فيها المجلدات `src` و `public`) وأفلتها بمكان الرفع
6. تحت اكتب أي وصف بسيط متل "رفع أولي" واضغط **Commit changes**

## الخطوة 2: ربط Vercel

1. روح على [vercel.com](https://vercel.com) واعمل حساب — الأسهل تسجل دخول بحساب GitHub مباشرة (زر "Continue with GitHub")
2. اضغط **Add New... → Project**
3. اختار الريبو يلي رفعته (`jamal-production-website`) واضغط **Import**
4. Vercel رح يتعرف تلقائياً إنه مشروع Vite — ما تحتاج تغيّر أي إعداد
5. اضغط **Deploy** وانتظر دقيقة-دقيقتين

بعد ما يخلص، Vercel بيعطيك رابط مباشر (مثلاً `jamal-production-website.vercel.app`) — هاد رابط موقعك الحي!

## الخطوة 3 (اختياري): ربط دومين خاص

إذا اشتريت دومين (مثلاً `djrabihjamal.com`) من Namecheap أو GoDaddy:
1. بصفحة المشروع على Vercel، روح لـ **Settings → Domains**
2. اكتب الدومين تبعك واضغط **Add**
3. Vercel بيعطيك تعليمات (سجلات DNS) تحطها بلوحة تحكم الدومين — عادة بياخد ساعات قليلة لين يشتغل

## كيف تحدّث الموقع لاحقاً

1. افتح الملف يلي بدك تغيّره على GitHub (غالباً `src/App.jsx`)
2. اضغط أيقونة القلم (Edit) بأعلى يمين الملف
3. امسح المحتوى القديم والصق الكود الجديد يلي بعطيك ياه
4. اضغط **Commit changes**
5. خلص — Vercel بيلاحظ التغيير وينشره لحاله خلال دقيقة-دقيقتين، بدون أي خطوة زيادة
